# Paste-ready tribute blocks for Giscus seeding

Staging file used to copy-paste tributes into the Giscus composer on
`/tributes/`. **Tracked in git as a record of what was posted** —
Jekyll-excluded from the built site.

Each of the 18 blocks below is inside a fenced code block for clean
copy-paste. Workflow:

1. In this file, click inside a fenced block (or triple-click to select
   the whole line, then extend).
2. Copy **only the content inside the fence** (not the ``` fence markers
   themselves).
3. Paste into the Giscus composer at
   https://v2.jozefasobkowicz.com/tributes/, click **Comment**.
4. Return here, move to the next block.

**Order:** chronological by tribute date, oldest first. Ties preserve
the order from [`_data/messages.yml`](_data/messages.yml). Six tributes
had no date recorded and are shown as **March 1, 2019** — the date of
Jozefa's passing — as a defaulted placeholder.

Polish/Ukrainian entries: proofread the original against
`_data/messages.yml` once during pasting to catch any Unicode drift.

> ⚠️ **English translations for messages 2–7, 9, and the Polish
> portions of 8 and 18 are AI-generated** (the Ukrainian translations
> for 1 and 15 were provided by the original senders and are
> authoritative).
> Please have a native Polish speaker review the AI-generated ones
> before pasting — these are permanent public tributes and nuance
> matters. Edit inline or replace as needed.

**Translation review notes** — judgment calls in the AI translations,
worth a second opinion during proofreading:

- **Diminutives.** Kept Polish diminutives (`Bożenko`, `Mateuszek`,
  `Cioci`) in the English translations where they add warmth. Anglicize
  if preferred (`Bożena`, `Matthew`, `Aunt`).
- **Message 3 — Jarek Zając.** Translated "cóż, życie!" as
  "well, such is life!" — colloquial. Gentler alternatives:
  "well, that's life"; "such is life".
- **Message 4 — Stanisław Zając.** "Zająców i Trybusów" rendered as
  "the Zając and Trybus families" (Polish uses declined plural forms;
  English needs the surnames + "families" for readability).
- **Message 7 — Katarzyna Motzko.** "Ciociu Bożenko, Wujku Rysku"
  translated Aunt/Uncle but kept the names in Polish diminutive form.
  Consider fully Anglicizing to "Aunt Bożena, Uncle Ryszard" if
  preferred.
- **Message 8 — John Majowski.** The Polish prayer line
  ("Wieczny odpoczynek…") was rendered as the standard English
  Catholic form: *"Eternal rest grant unto her, O Lord, and let
  perpetual light shine upon her, forever and ever, Amen."*

Attribution format follows [docs/github-runbook.md § 5](docs/github-runbook.md#5-seed-the-tribute-thread).

This file is tracked in git as a durable record of what was pasted,
and excluded from the built site via `_config.yml`.
